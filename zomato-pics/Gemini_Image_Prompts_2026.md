Every drink below is a **complete, self-contained prompt**. Say a drink name and use its block as-is.
---
## How this works in NotebookLM
1. Add as sources: **all the reference photos** in this folder + your **logo file** + **this document**.
2. Type a drink name (e.g. *"Kiwi Green Splash"*). NotebookLM returns that drink's full prompt block.
3. Paste the block into your image generator, attaching the two images it names (the reference photo + the logo).
4. Every image uses the SAME camera distance as Cafe Mocha, pulled back a few inches, so the whole set is consistent.

> NotebookLM itself does not create images - it retrieves the right prompt. Generate the image in Gemini / Nano Banana with that prompt + the two attached images.
